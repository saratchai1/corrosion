04 · From imagery to engineering result

ขั้นตอนที่จะทำให้ตอบได้ว่า “ถอยกี่เมตรต่อปี”

โครงเว็บและภาพระดับจังหวัดพร้อมแล้ว แต่การรายงาน erosion rate ที่รับผิดชอบต้องทำต่อเป็นกระบวนการวิเคราะห์แนวชายฝั่ง ไม่ใช่ปรับ UI ให้ดูเหมือนมีคำตอบ

01 · PROVINCE AOI

ภาพรวมทั้งจังหวัด

ขอบเขตจังหวัดและชายฝั่ง/เกาะทั้งหมด ใช้เป็น index map และจัดการ scene/mosaic ให้ครอบคลุมสม่ำเสมอ

02 · MULTI-DECADE IMAGERY

Landsat + Sentinel‑2

ใช้ Landsat ย้อนหลังถึงประมาณ 1990 สำหรับ long-term trend และ Sentinel‑2 สำหรับรายละเอียดช่วงหลัง

03 · SHORELINE EXTRACTION

แนวชายฝั่งรายปี/ฤดูกาล

จำแนก land-water interface ด้วย MNDWI/classification พร้อม QA mask และเก็บ uncertainty ของแต่ละ shoreline

04 · TIDE CONTROL

จับคู่หรือปรับระดับน้ำ

กรอง acquisition ให้ระดับน้ำใกล้กัน หรือ normalize shoreline ด้วย datum/DEM เพื่อไม่ให้ tide กลายเป็น erosion ปลอม

05 · DSAS TRANSECTS

คำนวณ NSM / EPR / LRR

วาง transect ตั้งฉากชายฝั่งและคำนวณการถอย/งอกเป็นเมตรต่อปี พร้อม confidence interval

06 · FIELD VALIDATION

RTK / Drone / Beach profile

ลงพื้นที่เฉพาะ hotspot เพื่อแยก erosion, accretion, inundation, sediment shift และ classification error
