# data/aoi
All AOI GeoJSON files in this directory use EPSG:4326 / CRS84.

- `samut_songkhram_aoi.geojson` is the original broad province-coast search AOI and remains provisional.
- `samut_songkhram_project_plots.geojson` contains only `91–98-STC` and `87-VSD`, selected from the pinned `mangrove-drone-dashboard` source. Official participating area values and geometry-calculated QA areas remain separate.
- `samut_songkhram_project_analysis_aoi.geojson` is a 2.5 km analytical buffer for imagery and nearby comparison pixels. It is not an official participating-area boundary.
